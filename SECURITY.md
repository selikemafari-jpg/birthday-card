# 🔒 Security Policy

## Supported Versions

This project is currently maintained on the latest version available in the main branch.

| Version        | Supported |
| -------------- | --------- |
| Latest         | ✅         |
| Older versions | ❌         |

---

## 🐛 Reporting a Security Issue

If you discover a security issue in this project, please do not publicly post sensitive information in an issue.

Instead, contact the project maintainer privately through GitHub.

Please include:

* A description of the issue
* Steps to reproduce it
* The potential impact
* Any suggested solution, if available

---

## ⚠️ Third-Party Assets

This project may contain or reference third-party assets.

Contributors should ensure that any assets they add have appropriate permission or licensing for their intended use.

Do not add private information, passwords, API keys, authentication tokens, or other sensitive credentials to the repository.
