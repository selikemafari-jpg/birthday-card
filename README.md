# 🎂 Interactive Birthday Card

A responsive and interactive birthday-card website built from scratch using **HTML, CSS, and JavaScript**.

The project was created as a personalized digital birthday experience rather than a traditional birthday message. It combines animations, music, memories, and interactive UI elements into a single web experience.

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/selikemafari-jpg/birthday-card.git
```

Open the project folder:

```bash
cd birthday-card
```

Then open `index.html` in your browser.

No build tools or frameworks are required.
